All deliverables from the M01-S03 plan are complete:

3. **Auth layout** — polished centered card with border/shadow, Kreyora wordmark, "Back to home" link, "Simulated authentication" disclaimer
4. **Seller workspace shell** — complete rewrite of `(seller)/layout.tsx`:
   - Desktop sidebar: Kreyora wordmark, workspace name, 3 nav groups (Core, Configure, Business) with 12 links and SVG icons
   - Active link state via `usePathname()` with `aria-current="page"`
   - Role-aware visibility: links hidden based on role (owner sees all; operator sees core only; viewer sees core + analytics/audit)
   - Mobile drawer navigation using Radix Dialog
   - Top bar: mobile hamburger, notification bell with badge, profile menu (Radix DropdownMenu) with user info, role badge, switch workspace, sign out
   - Demo role switcher in sidebar footer
5. **Workspace picker** (`/workspaces`) — lists tenants from `useIdentityClient().getWorkspaces()`, loading skeleton, workspace card with name/slug/role badge
6. **useSession hook** — loads session from mock identity client, provides `effectiveRole` with demo role override support, React Context-based
7. **Onboarding wizard** (`/onboarding`) — 7-step accordion stepper:
   - Steps: Store profile, Catalog readiness, Delivery rules, Payment setup, Channel connection, Assistant policy, Activation review
   - Status icons: completed (green check), incomplete (dot), blocked (warning), permission_denied (lock)
   - Content panels per status: completed shows date + edit button, incomplete shows form placeholder + save button, blocked shows prerequisite message, denied shows contact owner message
   - Progress bar with percentage, Previous/Next navigation, activation status section
   - Auto-focuses first incomplete step on load
8. **Dashboard** (`/dashboard`) — metrics cards (total orders, revenue, conversations, AI credits), setup progress bar linked to onboarding, low-stock alert, recent orders table with status badges, quick actions (add product, view inbox, check inventory), ViewerBadge for viewer role, loading skeleton
9. **All simulated operations** are clearly labeled with disclaimers

Nothing from the plan was omitted.
