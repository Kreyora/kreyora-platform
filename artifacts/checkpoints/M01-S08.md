## Design decisions

1. **Storefront admin sub-navigation**: All 4 storefront pages share a consistent `NAV_ITEMS` tab bar with active-state indicator. This keeps navigation predictable across profile, delivery, payments, and preview.

2. **Quota bar implementation**: Used native HTML `div` with `role="progressbar"` and ARIA attributes (`aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-label`). Width is controlled via inline `style` with a percentage cap at 100%. Level-based color mapping uses CSS custom properties for green/yellow/red and a Tailwind `bg-orange-500` for the 90% state.

3. **Analytics period selector**: Implemented as a button group with visual toggle state. Each period change triggers a fresh `getAnalytics()` call, demonstrating the mock adapter returning different fixture data per period.

4. **Settings danger zone**: The "Delete Workspace" button is always disabled and visually de-emphasized. This demonstrates the settings pattern without risk.

5. **Audit table responsiveness**: Details and correlation ID columns are hidden on smaller viewports (`hidden md:table-cell`, `hidden lg:table-cell`) to keep the table readable.
