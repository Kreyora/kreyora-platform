# M04-S06 Checkpoint — Contention, Isolation, and End-to-End Verification

**Status:** `REVIEW`

## Result

The M04 verification campaign passed. It exposed and fixed a real reservation defect: EF Core wraps PostgreSQL serialization failures as a transient `InvalidOperationException`; the reserve path had classified that as validation (`400`) rather than retrying. The service now treats that specific transient wrapper as retryable, with finite jittered backoff and a 20-attempt cap. It retains PostgreSQL `SERIALIZABLE` transactions, `FOR UPDATE` inventory-row locking, tenant scoping, and idempotency records.
