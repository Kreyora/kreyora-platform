## Implementation design

- **Components/modules changed:** GitHub Actions workflow and dependency-review policy; deterministic frontend and API-generation scripts; web Dockerfile; CI and contract documentation; narrowly scoped lint repairs needed for the new enforced lint gate.
- **Runtime or data flow:** The contract job applies migrations through the API's `--migrate` runner, starts the Development API, fetches `/openapi/v1.json`, normalizes only its host-dependent `servers[].url`, writes the committed snapshot, regenerates `v1.ts`, and fails if either generated file differs. ## Amendment — 2026-08-01: Final CI workflow structure

### Reason

The first GitHub-hosted pull-request run exposed a pnpm `11.12.0` self-installer regression before the repository install began. The repository owner also selected a narrower initial automation scope: automatic pull-request quality/security gates and manually dispatched Docker validation only.

### Changes

- Upgraded the declared and installed pnpm version from `11.12.0` to `11.13.0` in the root `packageManager`, the remaining `pnpm/action-setup@v6` step, and the web Dockerfile. Removing the contract/migration job also removed its former second pnpm setup step. The workflow sets `run_install: false` and retains an explicit `pnpm install --frozen-lockfile` command.
- Changed `.github/workflows/ci.yml` to the `Pull request CI` workflow, triggered only by `pull_request`.
- Kept automatic `backend`, `frontend`, and blocking `secret-scan` jobs. The Gitleaks job uses `fetch-depth: 0`, `GITHUB_TOKEN`, and the repository-managed `GITLEAKS_LICENSE` secret without printing or hard-coding it. It now uses `gitleaks/gitleaks-action@v3`, the Node-24-compatible release.
- Removed the automatic contract/migration, OpenAPI drift, and Dependency Review jobs. The dependency-review configuration file remains retained and unused for a future intentional re-enable.
- Moved API and web image validation to `.github/workflows/docker.yml`, which has only `workflow_dispatch` and two independently visible image-build jobs.
