# Checkpoint — M02-S01: Monorepo and Solution Topology

**Date:** 2026-07-27
**Status:** COMPLETE

## Scope

Establish the .NET backend solution structure within the monorepo, enforce Clean Architecture layer boundaries via project references and architecture tests, and provide a minimal runnable API.

## Deliverables

### Solution structure (`services/api/`)

```
services/api/
├── Kreyora.slnx                          # .NET 10 XML solution (10 projects)
├── Directory.Build.props                  # Shared: net10.0, nullable, warnings-as-errors
├── src/
│   ├── Kreyora.Domain/                    # Zero dependencies
│   ├── Kreyora.Application/               # References: Domain
│   ├── Kreyora.Infrastructure/            # References: Application (→ Domain)
│   ├── Kreyora.WebApi/                    # References: Infrastructure, Application, ServiceDefaults
│   ├── Kreyora.ServiceDefaults/           # Health checks, Aspire-compatible extensions
│   └── Kreyora.AppHost/                   # Aspire orchestration host (NuGet-based)
└── tests/
    ├── Directory.Build.props              # Suppresses CA1707 for test naming
    ├── Kreyora.UnitTests/                 # References: Domain, Application
    ├── Kreyora.IntegrationTests/          # References: Infrastructure, WebApi (WebApplicationFactory)
    ├── Kreyora.ArchitectureTests/         # References: all src projects (NetArchTest.Rules)
    └── Kreyora.ContractTests/             # References: WebApi (WebApplicationFactory)
```

### Root files

| File | Purpose |

### API endpoints

| Endpoint | Method | Purpose |
|---|---|---|

| `/health` | GET | Self health check (always healthy) |

### Architecture tests (6 tests)

- Domain must not reference Application, Infrastructure, or WebApi
- Application must not reference Infrastructure or WebApi
- Infrastructure must not reference WebApi

### Other tests

- 2 unit smoke tests (assembly marker loading)
- 2 integration tests (system info + health endpoint via WebApplicationFactory)
- 1 contract test (system info JSON shape validation)

## Design decisions

1. **`.slnx` format**: .NET 10 SDK defaults to the new XML solution format; no `.sln` file needed.
2. **Aspire via NuGet**: The Aspire workload is deprecated in .NET 10. Using `Aspire.Hosting.AppHost` NuGet package instead.
3. **`Directory.Build.props` inheritance**: Root props set common defaults; `tests/` overrides to suppress CA1707 (underscore test names).
4. **Assembly markers**: Each layer exposes a static marker class for architecture test assembly loading.
5. **NuGet vulnerability warnings suppressed**: NU1901/1902/1903 suppressed in props (transitive dependency issue, not a direct concern).
