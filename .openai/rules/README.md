# Codex Shared Standards

Codex follows the same project-wide coding and process standards as every other Kreyora agent.

The standards are located in `.claude/rules/`:

- `frontend.md`
- `backend.md`
- `testing.md`
- `documentation-and-checkpoints.md`

These files are named `.claude/rules/` for historical reasons; they are not Claude-specific. `docs/context/AGENT_CONVENTIONS.md` documents the shared multi-agent conventions and handoff workflow.
